## _**Завдання для попередньої підготовки:**_

_**Словник базових понять:**_

* **User Personas (Персони):** Це умовні портрети типових користувачів із їхніми характеристиками, потребами та проблемами. Вони допомагають команді зрозуміти, для кого створюється продукт.
* **Customer Journey Map / Journey Mapping (Мапування шляху користувача):** Схема, що показує, як користувач взаємодіє з продуктом крок за кроком, включно з його діями, емоціями та проблемами.
* **Problem Statement (Формулювання проблеми):** Чіткий і стислий опис ключової проблеми користувача, сформований на основі досліджень.
* **User Stories (Користувацькі історії):** Короткі описи потреб користувачів у зручному форматі, що пояснюють, яку цінність має надати продукт.
* **User Flow (Юзер флоу):** Візуальна схема послідовності кроків, які виконує користувач у межах конкретного сценарію.
* **Wireframes (Вайрфрейми):** Макети екранів, які показують розташування основних елементів інтерфейсу, таких як кнопки, поля форми чи зображення.
* **Usability Testing (Юзабіліті тестування):** Дослідження, яке проводиться для перевірки того, наскільки зручно використовувати інтерфейс для виконання конкретного завдання.

_**Відповіді на запитання попередньої підготовки:**_
1. Яка головна різниця між Figma та FigJam (для яких завдань кожен інструмент кращий)?
**Figma — інструмент для створення інтерфейсів.**
Використовується для:
* UI-дизайну (екрани, кнопки, форми)
* прототипів
* дизайн-систем
* передачі макетів розробникам.
___
**FigJam — онлайн-дошка для спільної роботи.**
Використовується для:
* брейнштормінгу
* створення user-flow
* мап ідей
* планування UX-досліджень
* воркшопів команди.
> **FigJam** — для обговорення та ідей, **Figma** — для створення самого дизайну.

2. Що таке "Двері Нормана" і як це поняття пов'язане з емпатією до користувача?
Don Norman описав поняття “Norman Doors” — це двері з неочевидним способом відкривання (наприклад, ручка виглядає так, ніби її треба тягнути, але двері треба штовхати).
